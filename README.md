# Call Center HR Analytics Project

## Role
HR Analyst

## Project Overview
This project focuses on analyzing employee turnover and workforce needs in a call center environment.

## Tools & Skills
- Microsoft Excel
- HR Analytics
- KPI Metrics
- Workforce Planning

## Responsibilities
- Analyzed employee turnover and workforce needs.
- Developed recruitment and selection criteria.
- Designed performance evaluation metrics and KPIs.
- Prepared HR plans to support employee performance and retention.

## Results
Identified workforce planning and recruitment priorities and developed performance evaluation metrics to support employee retention and performance.
